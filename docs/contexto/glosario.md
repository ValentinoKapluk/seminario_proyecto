# Glosario del Dominio — Epic Sneakers

Este documento define el vocabulario oficial del negocio para mantener consistencia en textos, etiquetas, variables y componentes.

| Término | Definición y Uso en la Interfaz |
| :--- | :--- |
| **Epic Sneakers** | Nombre comercial oficial de la marca y tienda. |
| **Zapatillas de Running** | Calzado técnico optimizado para correr (amortiguación, peso liviano, transpirabilidad). |
| **Zapatillas de Escalada / Trail** | Calzado de alta tracción y resistencia para terrenos de montaña y trekking. |
| **Catálogo** | Grilla de visualización de productos disponibles con especificaciones básicas. |
| **Modal / Ventana Emergente** | Capa flotante interactiva que muestra el detalle ampliado de una zapatilla sin abandonar la página. |
| **Talles y Colores** | Opciones de selección del calzado (ej. talles del 38 al 45 y combinaciones cromáticas). |
| **Descuentos y Promociones** | Banners e insignias destacadas (badges) que resaltan rebajas de temporada. |
| **Modo Oscuro (Dark Mode)** | Tema visual predeterminado del sitio (fondo azul noche y textos blancos/cian). |
| **Modo Claro (Light Mode)** | Tema alternativo conmutable (fondo blanco y textos contrastados). |
| **Gradiente Cian (Primario)** | Rango de color `#06b6d4` a `#3b82f6` utilizado en elementos de jerarquía principal. |
| **Gradiente Rojo (Secundario)** | Rango de color `#f43f5e` a `#ef4444` utilizado en promociones y llamados secundarios. |
| **Feedback de Formulario** | Alertas visuales inmediatas ante la validación de campos obligatorios o confirmación de envío. |
